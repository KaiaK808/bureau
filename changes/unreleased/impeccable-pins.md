section: Changed

- Supported Impeccable versions are now skill 4.9.0 and engine 0.1.23. **Upgrade:** installations with `design.impeccable.enabled: true` must separately install skill 4.9.0 with engine 0.1.23 using the guidance in `docs/configuration.md` (`impeccable install --project --providers=claude --no-hooks -y`; `--no-hooks` is required, and remove or disable the installed agents), then set `design.impeccable.skill_version` to `"4.9.0"` and `design.impeccable.engine_version` to `"0.1.23"` in `.bureau.json` together with the scripts resync, or remove both keys to follow the pins. Until then Bureau reports Impeccable as unavailable and stages continue without it. Installations with Impeccable off need no action beyond the resync: setup writes the new defaults, and an existing `.bureau.json` with the old values and `enabled: false` is unaffected. Validation: 23 offline fixture/stage tests passed via `bash tests/test_impeccable.sh -v`; `python3 scripts/render_docs.py` regenerated the manual, and `bash tests/test_docs.sh` confirmed source hashes and local links; `bash tests/test_no_internal_refs.sh` and `python3 scripts/changelog.py check` passed. The maintainer verified the official skill-v4.9.0 release archive against its published SHA-256, Bureau's 58-file tree digest against an installed copy, engine-v0.1.23 release asset digests against the skill's `scripts/engine-checksums.txt`, `verify()` availability with the new pins and rejection of the old skill pin, and the real engine's exit-2 JSON findings against the unchanged finding checks.
