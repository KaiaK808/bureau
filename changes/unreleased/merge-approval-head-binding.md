section: Fixed

- The merge gate still uses `gh pr view --json comments` to select the newest PR comment containing the `Code Review v2` heading. Both automatic merge routes now bind its `APPROVE` or `AUTO_APPROVE` to the reviewed head and target branch on both gate passes. The target branch can contain backticks, and its SHA may advance. Each pass checks base freshness against the same PR snapshot used for the binding. Bureau prepares the merge message before the final checks, unconditionally re-reads the approved target, checks ticket authorization immediately before merging, and checks merged state, merge commit and target after the merge. Wrong-target or still-uncertain outcomes log an error, post a Linear comment and hold with `needs-human` and exit `25`, without rollback or automatic merge retry; an uncertain result gets one fresh reconciliation read. A stale approval returns to Build Review with exit `20` and a `refreshed` report even if the lookup of earlier gate comments fails. The inline route reviews and cleans up against the PR's own advertised head, including same-named fork branches, force-pushes and deleted/pruned branches. A failed cleanup fetch cleans at the pinned review base and returns quiet retry `2` without `needs-human` or a cached tracking head. The acceptance brief credits a verdict only to its separately recorded reviewed head. Stale approvals leave the dispatcher's base-refresh allowance available. Shepherd uses `agents.max_review_rounds` as the separate stale-handoff limit per run, counting only after confirming the move to Build Review so a delayed Linear response cannot spend it twice. Confirmation honors human holds immediately and returns quiet retry `2` after one bounded polling budget if the move remains invisible. Shepherd preserves post-merge reconciliation reports without claiming that nothing merged or suggesting an ordinary gate retry. A definitive blocker such as a merge conflict returns `25` even if the base name is missing. A failed read with only undecided blockers returns `2`.
